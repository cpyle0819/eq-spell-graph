# Some eqlwiki zone pages have broken map images — check P1999 before giving up

Issue #36's Chardok entry couldn't get a map for a while. Both `[[File:Chardok top.png]]` (Post-Revamp page) and `[[File:Map chardok.jpg]]` (Pre-Revamp page) render as `mw:Error mw:File/Thumb` / `mw-broken-media` in the page HTML — the files were never actually uploaded to eqlwiki, on either version of the page. `curl`ing the page (`action=raw` or the rendered HTML) makes this checkable without a browser: a real map image resolves to a `<figure typeof="mw:File/Thumb">` with a working `<img src=...>`; a broken one keeps the `mw:Error` typeof and a `mw-file-element mw-broken-media` span instead of an `<img>`.

**Default is still: don't substitute a classic-EQ map for a missing eqlwiki one** — `decisions/eql-vs-classic-eq-zone-connectivity.md` already established that EQL zone layouts can diverge from classic EQ, and a Velious-era revamped zone like Chardok is exactly the kind of case where the divergence risk is highest.

**User-approved exception (migrations 315-318, Chardok/Great Divide/Kael Drakkal/The Wakening Land):** when eqlwiki's own upload is broken and the wiki content itself is otherwise a direct mirror of wiki.project1999.com's own page (same wikitext, same map filename, same numbered "Map Location Key" legend — eqlwiki was forked from P1999's content), the user judged the map layout itself unlikely to have drifted even though other zone facts might have, and asked for the P1999-hosted copy of that exact image as a one-off fallback rather than leaving the zone mapless indefinitely. This is a per-zone call, not a blanket rule — check the eqlwiki page's own wikitext against P1999's before assuming they still match, and keep bestiary/vendor/faction data sourced from eqlwiki as before (P1999 is a source only for the specific broken image, nothing else).

**Before falling back to P1999:** check for a working image *before* investing time in legend transcription — a quick `curl <page> | grep -o 'File:[^"]*\.\(jpg\|png\|gif\)\|mw-broken-media'` on the target page is enough to tell up front whether a zone's map is worth pursuing this pass. If neither eqlwiki nor P1999 has a working upload, leave the zone's bestiary (if sourceable) and skip only the map, same as migration 157 did for Chardok's bestiary while its map stayed blocked.
