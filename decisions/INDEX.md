## Faction System (EQ Domain)

- [Three dimensions determine vendor access](three-dimensions-determine-vendor-access.md) — Race (guard KOS), primary class (merchant refusal), and deity (compounds with class) — the planner resolves the worst standing across all three.
- [Secondary class does NOT affect faction](secondary-class-does-not-affect-faction.md) — In EQ, only primary class restricts deity selection, and only deity + race drive faction hits.
- [Standing thresholds (eqlwiki Faction page)](standing-thresholds.md) — Scowls/Threatening → KOS, Dubious → won't sell, Apprehensive → bad prices, Indifferent+ → normal.
- [Faction data is approximate](faction-data-is-approximate.md) — Standings are inferred from wiki research, not exact numerical values.
